# Data

**Source:** NASA Exoplanet Archive, *Kepler Objects of Interest — Cumulative table*
https://exoplanetarchive.ipac.caltech.edu/ → Data → Kepler → KOI Table (Cumulative) → Download Table → CSV (all columns)

The file `kepler_cumulative.csv` is included in this repository. If you download it again, save it here under the same name.

- Snapshot used: 9,564 KOIs (4,839 FALSE POSITIVE, 2,748 CONFIRMED, 1,977 CANDIDATE)
- Download date: 6 November 2026 (timestamp in the file header)
- Dispositions in the archive change over time, so a newer download may give slightly different numbers.
